# 论文速读：A New Pipeline for Knowledge Graph Reasoning Enhanced by LLMs Without Fine-Tuning

## 一句话总结
本文提出了一种无需微调的大语言模型辅助知识图谱推理（KGR）三阶段流水线，通过知识对齐（将 LLM 知识注入 KG 以弥补不完整性）、结构感知 KGR 推理、以及实体重排序三个阶段协同工作，在 WN18RR 和 FB15K-237 数据集上均显著提升了传统 KGR 模型的性能。

## 研究问题与动机
1. **KG 推理严重依赖图谱结构，但真实 KG 普遍存在不完整性**，导致传统基于嵌入或路径的 KGR 模型性能受限。
2. **直接让 LLM 充当实体推理器面临巨大挑战**——实体空间过于庞大，且后处理匹配预测结果与实体名称容易失败（Tan et al., 2023）。
3. **已有方法需对开源 LLM 进行微调（如 KGT5、CSProm-KG、KG-LLaMA），成本高昂且无法应用于闭源 LLM（如 ChatGPT）**，限制了方法的普适性。
4. **如何在不微调的前提下，利用 LLM 的丰富世界知识与 KG 的结构化信息协同增强 KGR**，仍是一个待解决的问题。

## 核心贡献（创新点）
1. **提出无需微调的三阶段流水线（知识对齐 → 推理 → 实体重排序）**：与现有微调方法（KGT5、KG-LLaMA 等）本质不同，本文利用 Prompt 引导 LLM 知识注入 KG，不修改 LLM 参数，可直接兼容闭源与开源 LLM。
2. **设计了三种知识对齐策略（封闭域、开放域、半封闭域）**：分别通过多选题选择预定义关系、自由生成细粒度语义描述、以及通过 Sentence-BERT 语义匹配映射回预定义关系，为不同 KG 模式提供灵活的知识注入方式。
3. **提出实体重排序阶段**：利用 LLM 的语义排序能力对 KGR 模型的 top-k 候选实体进行重排，进一步召回正确答案，这是对传统 KGR 仅依赖结构推理的有效补充。
4. **系统揭示了开放域对齐的性能增强机制**：通过案例研究证明 LLM 能生成超越预定义 KG 关系的细粒度语义信息，且 RotatE 能有效捕获这些新词与预定义关系之间的语义相似性。

## 方法详解

### 整体架构
三阶段流水线：**知识对齐（Alignment）→ KG 推理（Reasoning）→ 实体重排序（Reranking）**。

### 3.1 知识对齐
目标：将 LLM 中存储的知识显式关联到 KG 模式，以边缘形式注入 KG，弥补不完整性。

- **封闭域策略（Closed Domain）**：将预定义的 KG 关系作为多选题选项，要求 LLM 输出正确选项的大写字母，严格对齐 KG 模式，在语义和结构两层对齐。
- **开放域策略（Open Domain）**：以简答题形式诱导 LLM 生成两实体间的关系描述，不限制输出内容必须遵循预定义关系，所有输出作为 enriched edges 加入 KG，保留全部语义信息。
- **半封闭域策略（Semi-Closed Domain）**：先用开放域策略获得 LLM 输出，再用 **Sentence-BERT** 计算输出与所有预定义关系的语义相似度，选取最高相似度对应的预定义关系，兼顾可解释性与信息保留。

### 3.2 KG 推理
- 封闭域与半封闭域：与预定义关系一致，可直接用任意结构感知 KGR 模型训练。
- 开放域：输出为文本句子，使用 **word2vec** 初始化句子中各词的嵌入，训练过程中联合更新，以句子内所有词嵌入的均值作为 enriched edge 的嵌入表示，使下游 KGR 模型同时利用两种形式的知识。

### 3.3 实体重排序
- 输入：KGR 模型打分最高的 top-k 候选实体名称（k=10 或 20，最优 k=20）。
- 利用 LLM 的语义知识，根据候选实体与查询的语义关联性进行重排序，从结构推理结果的基础上进一步召回正确答案。
- ChatGPT temperature=0（保证可靠性），知识对齐阶段 temperature=0.3（增加多样性）。

## 实验与结果

### 数据集
- **WN18RR**：11 个关系，构建 10%、40%、70%、100% 四个稀疏度版本。
- **FB15K-237**：237 个关系，同样构建四个版本。
- 新事实与原始事实比例为 1:10（WN18RR 共 8,684 条新事实，FB15K-237 共 27,212 条）。
- 允许 LLM 输出 "no relation"。

### 基线
- 零样本 LLM：ChatGPT zero-shot、LLAMA3-70B zero-shot
- 传统 KGR：RotatE（嵌入-based）、MultiHopKG（路径-based）
- 本文流水线以 RotatE 和 MultiHopKG 为基础

### 主要结果（最优设置）

**WN18RR（LLAMA3-70B + RotatE，三阶段全开）：**

| 版本 | MRR | Hits@3 |
|------|-----|--------|
| 10% | 0.292 | 37.0 |
| 40% | 0.297 | 36.7 |
| 70% | 0.337 | 38.9 |
| 100% | 0.521 | 60.7 |

相比 RotatE 基线（100%：MRR=0.431，Hits@3=44.2），提升约 **+21%**（MRR）和 **+37%**（Hits@3）。

**FB15K-237（ChatGPT + RotatE，三阶段全开）：**

| 版本 | MRR | Hits@3 |
|------|-----|--------|
| 10% | 0.247 | 26.3 |
| 40% | 0.276 | 29.6 |
| 70% | 0.290 | 31.1 |
| 100% | 0.403 | 43.4 |

相比 RotatE 基线（100%：MRR=0.276，Hits@3=30.6），提升约 **+46%**（MRR）和 **+42%**（Hits@3）。

### 关键结论
- 稀疏数据集上的提升幅度大于完整数据集，说明本方法在 KG 不完整场景下尤为有效。
- ChatGPT 与 LLAMA3-70B 表现相当，验证方法对闭源/开源 LLM 的兼容性。
- 开放域对齐在 WN18RR（抽象关系）上最优，封闭域对齐在 FB15K-237（具体关系）上最优。
- 实体重排序阶段带来显著增益（Hits@3 提升 +3.4% ~ +10.9%），且 k=20 优于 k=10。
- 知识稳定性分析（KS@k）表明封闭域与半封闭域更稳定，开放域因引入多样输出略有性能波动。

## 相关工作脉络
1. **传统 KGR 模型（RotatE、TuckER、MultiHopKG 等）**：基于结构化嵌入或路径推理，忽略实体/关系的语义，严重依赖 KG 结构完整性。本文与之不同——保留并增强这些模型，而非替代。
2. **微调 LLM 用于 KGR（KGT5、KG-S2S、KG-LLaMA、KoPA）**：将 KG 结构以序列方式输入 LLM 并微调，成本高昂且不适用于闭源 LLM。本文的核心差异在于**零微调**，仅通过 Prompt 调用 LLM。
3. **无微调 LLM 辅助 KGR（MPIKGC、KICGPT）**：MPIKGC 依赖描述型 KGR 模型，无法处理不相连实体；KICGPT 聚焦提示工程而非优化 KGR 模型本身。本文从**对齐**与**重排序**两个视角联合优化，适用范围更广。
4. **信息检索中的 LLM reranking（Zhu et al., 2024）**：本文借鉴该思路，将 LLM 作为实体重排序器，是首次将其系统引入 KGR 任务。
5. **LLM 作为知识库（LAMA, Petroni et al., 2019）**：LAMA 评估 LLM 补全实体三元组的能力；本文反向利用 LLM 补全**缺失关系**，并注入 KG 以增强下游推理。

## 局限性与未来方向
1. **LLM 输出质量不可控**：无法在调用前预判输出是否有价值，存在幻觉、冗余正确信息、格式错误等风险（见 Appendix E 的错误分析）。
2. **开放域策略可能引入噪声**：FB15K-237 等具体关系数据集上，开放域输出的冗余实体属性信息会干扰下游训练，需根据数据集特性选择合适的对齐策略。
3. **未来方向**：① 增加修正模块，利用 KGR 模型能力对 LLM 输出进行后验纠错；② 结合 RAG 技术进一步提升知识对齐和重排序质量；③ 探索该方法在其他 KG 相关任务中的迁移应用。

## 研究启发与可借鉴点
1. **"知识对齐"范式可迁移**：将 LLM 世界知识显式注入结构化知识库，而非让 LLM 直接输出答案，这一思路可迁移到实体链接、关系抽取等任务。
2. **三种对齐策略提供了不同约束强度的通用模板**：封闭/开放/半封闭策略本质上是对"知识保真度"与"信息丰富度"的权衡，可根据下游任务的数据特性灵活选用。
3. **LLM 作为 reranker 的设计简洁高效**：仅需 top-k 候选实体名称，无需额外微调，即可显著提升 Hits@k，适合部署在资源受限场景。
4. **用 word2vec 均值初始化 enriched edge 嵌入的方法**：为开放域文本边融入传统 KGR 模型提供了一种实用的低代价方案，避免了重新设计嵌入架构。
5. **数据稀疏度梯度实验设计**：构建 10%/40%/70%/100% 多版本数据集系统评估，是验证方法在不完全知识场景下鲁棒性的优秀实验范式。

## 关键术语表
- **Knowledge Graph Reasoning (KGR)**：给定知识图谱中的头实体和关系，预测缺失尾实体（或反之）的链接预测任务。
- **知识对齐（Knowledge Alignment）**：将 LLM 中存储的世界知识通过 Prompt 引导，以边的形式注入 KG 模式，以弥补 KG 的不完整性。
- **封闭域对齐（Closed Domain Alignment）**：以多选题形式约束 LLM 从预定义关系中选择，输出严格符合 KG 模式。
- **开放域对齐（Open Domain Alignment）**：允许 LLM 自由生成实体间关系描述，保留更细粒度的语义信息。
- **半封闭域对齐（Semi-Closed Domain Alignment）**：用 Sentence-BERT 将开放域输出与预定义关系做语义匹配，映射回 KG 模式。
- **Hits@k**：评估指标，指正确答案出现在预测结果前 k 个位置的比例。
- **MRR（Mean Reciprocal Rank）**：评估指标，指所有测试样本的倒数排名的均值，综合考虑排序质量。
- **Knowledge Stability (KS@k)**：衡量对齐后原 KG 知识未被破坏的程度，即原正确预测仍保持在前 k 名的比例。
