# 论文速读：Noise-Novels-Numbers-A-Framework-for-Detecting-and-Categoriz

## 一句话总结
本文提出了一套结合主题模型检索与BERT细调的分类框架，用于在丹麦与挪威文学文本中自动检测并分类“噪声”，并基于19世纪末超过800部小说构建了开源标注数据集，实证量化追踪了斯堪的纳维亚“现代突破”时期文学中噪声感知的历时演变。

## 研究问题与动机
- **核心问题**：如何大规模、客观地量化历史文学文本中“噪声”（soundscapes）的出现频率与声源类别，弥补传统文学与声音研究依赖小样本经典文本的局限。
- **现有方法不足**：既往研究多聚焦20世纪现代主义先锋作品，缺乏对19世纪大众/现实主义文学的声音感知进行跨文本的历时计算分析；传统人文方法难以处理百万级历史文献的声学表征。
- **概念操作化挑战**：噪声被定义为“偏离的听觉行为”或“打破沉默的声音”，在文学中常与音乐、自然声交织，需明确的分类体系与标注规范才能进行自动化识别。
- **历史语境需求**：19世纪末斯堪的纳维亚经历快速城市化与工业化，作者假设文学中的噪声描摹与该时期的“听觉时代”及公众敏感度上升存在关联，需计算证据予以验证。

## 核心贡献（创新点）
- 提出“主题模型检索 + 细调PLM分类”的双阶段检测框架，实现了从百万级历史语料中高效、可扩展地抽取噪声片段。
- 构建首个针对北欧19世纪文学的噪声标注数据集，包含二元检测标签与四类细粒度源标签（非人造/人造/未定义/音乐），并开源代码与数据。
- 将计算语言学方法引入声音史研究，首次量化追踪1870-1899年丹-挪小说中噪声比例的历时上升轨迹（相对增幅超50%）。
- 系统对比历史专用模型与通用语言模型在噪声识别上的表现，发现DanskBERT在跨语境泛化上更具鲁棒性，为低资源/历史文学的计算分析提供方法参照。

## 方法详解
- **语料与预处理**：采用MeMo语料库（859部丹/挪小说，>6400万词，19世纪末），按段落切分，超长段落截断为50词片段，共得1,936,527个片段。
- **主题模型筛选**：使用BERTopic对全量片段聚类，人工筛选与噪声概念相关的15个主题（含lyd/støj/larm/råbe/skreg等词族），提取5,700个候选片段。
- **两阶段标注**：第一阶段由历史学家与文学学者进行二元标注（噪声/非噪声），依据“打破沉默”的操作性定义，过滤否定句式、隐喻与无关片段，获5,917条正负样本，Cohen’s Kappa=0.85。第二阶段在预测结果上进一步标注噪声源类别（Non-human made T / Human-made H / Undefined N / Music M），共1,874条，Kappa=0.81。
- **模型训练**：选用DanskBERT、DFM (Large)、MeMo-BERT-03、NB-BERT-base四个预训练模型，全参数fine-tune，batch size=32，20 epochs，AdamW优化器，learning rate=1e-3，以加权F1为评估指标。
- **历时预测**：将表现最优的DanskBERT部署至全量193万片段，统计噪声比例随年份的变化及各分类的时序分布。

## 实验与结果
- **噪声检测**：DanskBERT测试集F1最高达0.83（Precision 0.82, Recall 0.59）；MeMo-BERT-03验证集F1 0.90但测试集降至0.80；DFM (Large) 验证0.81/测试0.55，泛化能力最弱。
- **噪声分类**：DanskBERT与MeMo-BERT-03在测试集上均取得0.83的F1，DanskBERT在零样本跨域泛化上表现更稳定。
- **历时分析**：全库预测出220,378个噪声片段。1870s至1890s噪声占比呈现超50%的相对增长，1890年代末趋于平稳或略降；四类噪声的分布比例在时间轴上保持相对稳定，未出现结构性偏移。
- **结论**：验证了19世纪末文学中“噪声关注度”显著上升的假设，且趋势与文化史中“听觉时代”的到来相吻合；人类活动噪声始终维持高位，与欧洲大都市的公共空间管控史实一致。

## 相关工作脉络
- 数字人文中的历时主题建模（LDA、D-ETM、Structural Topic Models）：本文方法同源，但聚焦声学语义而非通用主题，并引入细粒度分类任务而非仅做主题prevalence追踪。
- 声音研究与文学声景分析（Schafer, Toth, Lambrecht等）：前人多为小范围文本的定性/近读研究，本文首次将其扩展至百万级远读，实现量化实证。
- 历史语言预训练模型（MeMo-BERT系列、DanskBERT、NB-BERT-base）：本文系统对比了专用历史模型与通用模型的性能差异，修正了“领域越专用越好”的直觉假设。
- 低资源/历史语料标注与评估：本文采用双专家标注与Cohen’s Kappa一致性检验，为同类人文计算项目提供了可复用的标注协议参考。

## 局限性与未来方向
- 语料与地域局限：仅限19世纪末丹麦与挪威小说，结论外推至其他语言、时期或体裁需谨慎。
- 分类维度简化：为保模型预测力，仅按声源分类，忽略了空间（城乡）、时代细分等关键文化变量。
- 上下文缺失：片段级预测难以捕捉叙事结构、人物视角及声音描写在情节中的功能，可能丢失文学性内涵。
- 未来方向：拓展至工业化影响分析、城乡声景对比、与现代丹麦小说及城市档案（民事投诉）进行跨语料比较，并开展噪声相关词汇的lexical diversity分析以探究心理认知层面。

## 研究启发与可借鉴点
- “主题检索 + 人工筛选 + 监督微调”的三阶段管线设计，可无缝迁移至其他感官现象（如气味、触觉）或特定情感/主题的历史文本挖掘任务。
- 对边界模糊类别（如音乐 vs 噪声、混合声源）的处理策略（设为独立类别或按主导源标注）为细粒度分类任务提供了实用的标注妥协方案。
- 实验对比揭示了“领域专用历史模型”与“通用多语言模型”在不同计算人文任务上的性能差异，提示后续研究应根据任务目标（ nuanced语义理解 vs 泛化检测）灵活选择基座。
- 历时分布可视化与历史假设验证的结合范式，可为文化史研究提供可量化的证据链，增强人文学科的计算论证力度。

## 关键术语表
- **Soundscape (声景)**：特定环境中由自然、人造及社会活动共同构成的声音环境及其文化感知。
- **Diachronic Analysis (历时分析)**：考察语言特征或文化现象在时间长河中的演变轨迹与规律。
- **BERTopic**：基于BERT嵌入与类标签TF-IDF的神经主题建模工具，用于从大规模文本中聚类主题。
- **DanskBERT / MeMo-BERT-03**：针对丹麦语优化的预训练语言模型，前者为通用高质量丹麦模型，后者为在文学语料上继续预训练的历史专用模型。
- **Cohen’s Kappa**：衡量两名标注者之间一致性程度的统计指标，排除随机巧合的影响。
- **Modern Breakthrough (现代突破)**：19世纪中后期斯堪的纳维亚地区的文学与社会现实主义运动时期。
- **Noise as “silence-breaking”**：本文采用的操作性定义，指文本中明确提及的、打破静默状态的任何声音事件（含中性描写）。
